# Nour Musleh — Portfolio Website

A responsive, static portfolio website designed for Project Manager, Project Coordinator, Product Owner, and Digital Transformation opportunities in the UAE.

## Included
- `index.html` — website content
- `style.css` — responsive Corporate Executive styling
- `script.js` — mobile navigation and current year
- `assets/` — place your CV PDF here

## Personalize before publishing
1. Replace the LinkedIn URL in `index.html` with your actual LinkedIn profile URL.
2. Add your CV PDF at `assets/Nour_Musleh_Resume_2026-09.pdf`.
3. Review all content, dates, project names, and role descriptions before publishing.
4. Consider replacing `Nour Musleh` with your preferred display name only if needed.

## Publish with GitHub Pages (free)
1. Create or sign in to a GitHub account at https://github.com/.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
6. Wait for the deployment to finish. Your site will be at `https://YOUR-USERNAME.github.io/`.

GitHub Pages provides free hosting for public repositories on GitHub Free. A custom domain is optional and usually costs money; the default `github.io` address is free.

## Accuracy and confidentiality
The case studies are high-level summaries based on the supplied CV. No project outcomes, performance metrics, or confidential deliverables have been invented. Verify project naming and ensure the content is approved for public disclosure before publishing.
